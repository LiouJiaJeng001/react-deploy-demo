② 部署到雲端並綁定網域

按「執行下一步」依序跑完整流程。這裡是流程示意，沒有真的部署。

  1. 1程式碼推到 GitHubgit push origin main
  2. 2雲端平台連結儲存庫並建置npm run build
  3. 3設定環境變數（資料庫連線字串）DATABASE_URL
  4. 4預覽網址檢查preview.example.app
  5. 5綁定自訂網域、DNS 生效、自動 HTTPSCNAME
